- Automatically excluded from public repo
- Clear visual indicator of private status
- No need to manually list in PRIVATE_DIRS

## When to Make a Skill Private

Move a skill to private if it contains:
- Personal information or PII
- Company-specific references
- Internal workflows or proprietary methods
- Personal coaching or journaling content
- Job application tracking
- Sensitive decision-making frameworks
